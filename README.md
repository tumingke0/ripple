# 涟漪（Ripple）

**一圈一圈，慢慢静下来。**

涟漪是一款安卓上的自控工具：到点让手机安静下来，给刷不停的 App 定个每日时长；想放松规则或卸载，先等一会儿。

- **官方网站**：<https://tumingke0.github.io/ripple/>
- **下载最新版（v0.1.0）**：[ripple-v0.1.0.apk](https://github.com/tumingke0/ripple/releases/download/v0.1.0/ripple-v0.1.0.apk)（52.0 MB，Android 8.0 及以上）
- **历史版本与更新说明**：<https://github.com/tumingke0/ripple/releases>

## 主要功能

- **专注时段**：在设定的时间段里，只允许打开你事先选好的少数几个 App。
- **每日时长**：给短视频、游戏等 App 设定每天最多可用的时长，用完当天打不开，0 点重置。
- **防止一时冲动卸载**：开启后，想放松规则或卸载涟漪需要先等一会儿（默认 15 分钟），或请亲友输入解锁码。
- **系统必需不受影响**：电话、短信、闹钟、日历、相机、输入法、系统钱包和系统设置始终可用。
- **本地隐私保护**：无账号、无广告、无统计，所有规则与使用记录只保存在你的手机本地。
